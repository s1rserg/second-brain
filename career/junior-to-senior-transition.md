# What Actually Separates Junior and Senior Engineers

## Writing Less Code, Solving More Problems
When I was starting out, I measured my productivity by lines of code merged and the cleverness of my abstractions.
- Junior mindset: "How do I build this complex, reusable generic framework for our feature?"
- Senior mindset: "Do we even need to build this? Can we delete existing code or use an off-the-shelf primitive?"
- True seniority isn't about knowing obscure language syntax; it's about predicting how this code will fail in production 6 months from now when you're on vacation.

## Ownership and Managing Up
A junior engineer waits for tickets to be defined and stops when the PR is merged.
- A senior engineer follows the change to production, watches the Datadog metrics, verifies user feedback, and ensures error budgets aren't blown.
- Don't bring your manager problems without at least two potential solutions and your explicit recommendation on which one to take.
